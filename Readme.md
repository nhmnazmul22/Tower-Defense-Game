# 🛡️ Goblin Siege - Tower Defense Game

Goblin Siege is a strategic tower defense game where players must protect their main base from waves of dangerous goblins using different types of defensive towers.

---

# 🎮 Game Overview

In this game, players defend their kingdom against endless goblin attacks. Players can build and upgrade multiple types of defense towers to stop enemies before they destroy the main tower.

The game becomes more challenging after every round as enemies gain more power, speed, and health.

---

# 🏰 Defensive Towers

Players can build different types of towers, including:

- 🏹 Archer Tower
- 💣 Cannon Tower
- 🚀 Mortar Tower
- 🔫 Machine Gun Tower
- ⚡ More advanced towers coming soon

Each tower has unique:
- Damage
- Attack range
- Attack speed
- Upgrade system

---

# 👹 Goblin Enemies

Different goblins have different abilities, movement speeds, and health levels.

## Basic Goblins
- Boogerfang
- Snifflesnot
- Pickletoes
- Stinkcrumb

## Boss Enemy
- 👑 Gorzak the Devourer

Boss enemies are stronger, tougher, and appear in special waves.

---

# ⚔️ Gameplay Features

## ✅ Difficulty Selection
Before starting the game, players can choose:
- Easy
- Medium
- Hard
- Nightmare

## ✅ Wave / Round System
Players can select how many rounds they want to survive.

After each completed round:
- Goblins become stronger
- Enemy speed increases
- Boss difficulty increases

---

# 💰 Coin & Upgrade System

Players earn coins by killing goblins.

Different goblins reward different amounts of coins.

Coins can be used to:
- Upgrade towers
- Unlock stronger defenses
- Build new towers during gameplay

---

# 🧠 Strategy System

Winning requires:
- Smart tower placement
- Resource management
- Proper upgrades
- Defensive planning

---

# 🏆 Win Condition

If the player survives all waves successfully, they win the game.

### Victory Message Example
> "Congratulations! You defended the kingdom and defeated the goblin invasion!"

---

# ☠️ Lose Condition

If goblins destroy the main tower, the player loses the game.

### Defeat Message Example
> "Defeat is not the end — improve your strategy and defend the kingdom again!"
